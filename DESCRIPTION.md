# XanMod Tools

tools for xanmod

The repo currently provides a matching `perf` tool and Debian package for XanMod kernels where a corresponding `linux-tools` package is not available from the distribution repositories.

## Current distribution

- Prebuilt kernel-specific `.deb` packages
- Signed APT repository for Ubuntu 24.04 (Noble), amd64
- GitHub Actions builds from the exact XanMod source tag
- GitHub Releases for downloadable artifacts
